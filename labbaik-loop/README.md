# labbaik-loop · จำลองอุมเราะห์ 3 มิติ

เว็บจำลองการทำอุมเราะห์ 9 ขั้นตอน จัดหน้าจอแบบเดียวกับ simulator.syumra.id (แถบขั้นตอนด้านบน แผงแนะนำซ้าย ตัวละครตรงกลาง แผงสร้างตัวละครขวา) เนื้อหาเป็นภาษาไทย ตามแนวทางมัซฮับชาฟิอีย์

- ขั้น 1–4 และ 9 อยู่ใน "สตูดิโอตัวละคร" (สร้างตัวละคร เตรียมตัว เส้นทางบิน มีกอต ใบบันทึก)
- ขั้น 5–8 เดินจริงในมักกะฮ์ 3 มิติ: ฏอวาฟ (นับรอบอัตโนมัติ), ละหมาดหลังมะกอมอิบรอฮีม + ดื่มซัมซัม, สะแอ 7 เที่ยว, ตะฮัลลุล
- โหมดสำรวจ 3 เมือง สร้างจากผังเมืองจริง (ไม่ต้องใช้คีย์):
  - **มักกะฮ์**: ตึกและหอนาฬิกาตามตำแหน่งและความสูงจริง ภูเขาหินรอบเมือง โถงฮะรอมมีพรม ซุ้มโค้ง โคมไฟ
  - **มะดีนะฮ์**: มัสยิดนะบะวีย์ที่เดินเข้าไปข้างในได้ (ประตูตามหมายเลขจริง อัรเราะฎะฮ์ โดมเขียว หออะซาน 10 หอ ลานกลางแจ้ง) ร่มยักษ์รอบลาน อัลบะกีอ์ กุบาอ์ กิบลาตัยน์ อุฮุด ญะบัลสะลัอ์
  - **อัลอักศอ**: โดมแห่งศิลา (เดินเข้าไปเห็นศิลาได้) ลานยกระดับ บันไดและซุ้มโค้ง 8 จุด โดมโซ่ มัสยิดอัลกิบลีย์ อัลกาส หออะซาน เมืองเก่าและกำแพงเมือง ภูมิประเทศจริง
  - กล้อง: ลากขึ้น/ลงเพื่อเงยหรือก้มมอง ลากซ้ายขวาเพื่อหมุน สองนิ้วถ่าง/หุบเพื่อซูม ปุ่มรูปตาหรือ V = มุมมองสายตา (ซูมเข้าสุดก็เข้ามุมมองนี้) PageUp/PageDown = เงย/ก้ม
  - สถานที่ที่ยังไม่ได้สร้างจากแผนที่จริง (มินา อะเราะฟะฮ์ มุซดะลิฟะฮ์ ญะมะรอต ญะบัลนูร ญะบัลษูร ตันอีม) ปิดไว้ก่อน และเดินออกนอกเขตที่สร้างเสร็จไม่ได้
  - ทุกเมืองมีคนเดินไปมา รถยนต์วิ่งตามถนนจริง (เลี้ยวที่ทางแยก หยุดเมื่อมีคนข้างหน้า) และไฟหน้าต่างตอนกลางคืน

## 1. เปิดเว็บในเครื่อง

ดับเบิลคลิก **`เปิดเว็บ.bat`** แล้วเว็บจะเปิดที่ http://localhost:8080 เอง (ปิดหน้าต่างดำเพื่อหยุด)

ห้ามเปิด `index.html` ด้วยการดับเบิลคลิกโดยตรง เพราะเบราว์เซอร์จะบล็อกการโหลดโค้ด ไม่ต้องติดตั้ง Node.js หรือ Python ต้องต่ออินเทอร์เน็ต เพราะไลบรารี 3 มิติโหลดจาก CDN

## 2. เปิดแผนที่ 3 มิติจริงของมักกะฮ์ (Google Photorealistic 3D Tiles)

ถ้ายังไม่ใส่คีย์ เว็บจะใช้ "ฉากจำลอง" ที่สร้างจากโค้ดแทน (ดูเป็นเกม) ใส่คีย์แล้วจะเห็นเมืองและมัสยิดจากภาพสแกน 3 มิติของจริง

1. เข้า https://console.cloud.google.com สร้างโปรเจกต์ และผูกบัญชีชำระเงิน (Google มีโควตาฟรีรายเดือน เกินแล้วคิดเงินตามการใช้งาน ตรวจราคาล่าสุดที่หน้า Pricing ของ Map Tiles API)
2. ไปที่ **APIs & Services → Library** ค้นหา **Map Tiles API** แล้วกด Enable
3. ไปที่ **APIs & Services → Credentials → Create credentials → API key**
4. กดแก้ไขคีย์ แล้วจำกัดการใช้งาน
   - Application restrictions: **Websites** ใส่ `http://localhost:8080/*` และโดเมนจริงของคุณ
   - API restrictions: เลือกเฉพาะ **Map Tiles API**
5. เปิดไฟล์ `config.js` แล้ววางคีย์ที่ `googleApiKey: 'วางคีย์ตรงนี้'`

ทางเลือก: ใช้ Cesium ion (https://ion.cesium.com) แทน ตั้ง `mapProvider: 'cesium'` และใส่ `cesiumIonToken` (asset `2275207` คือ Google Photorealistic 3D Tiles ผ่าน Cesium)

### ข้อจำกัดของแผนที่จริงที่ควรรู้

- ภาพสแกนของ Google สวยมากเมื่อมองจากมุมสูง แต่เมื่อเดินระดับพื้นจะเห็นความละเอียดจำกัด และมีภาพคนที่ถูกสแกนติดอยู่ในพื้น
- อาคารที่มีหลังคา (เช่น ทางเดินสะแอ) ภาพสแกนเห็นแค่หลังคา ขั้นสะแอจึงสลับเข้าไปในฉากภายในมัสอาที่สร้างเอง
- เดินทะลุอาคารในแผนที่จริงได้ (ไม่มีข้อมูลผนัง) ยกเว้นกะอ์บะฮ์
- ต้องแสดงชื่อแหล่งข้อมูลของ Google ตามเงื่อนไขการใช้งาน เว็บแสดงไว้ที่ด้านล่างจอแล้ว ห้ามลบ
- ถ้าแผนที่หมุนไม่ตรง (กะอ์บะฮ์ไม่อยู่กลางลาน) ปรับ `mapRotationDeg` ใน `config.js`
- ถ้าคีย์ผิดหรือโหลดไม่ได้ เว็บจะแจ้งเตือนแล้วสลับไปฉากจำลองเอง

## 3. ใส่โมเดลตัวละครแบบสมจริง

ตอนนี้ตัวละครเป็นหุ่นที่สร้างจากโค้ด ความสมจริงระดับเว็บต้นฉบับต้องใช้ไฟล์โมเดล 3 มิติที่มีโครงกระดูก (rig) ดูวิธีใน `assets/characters/README.md`

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้าจอ |
| `styles.css` | หน้าตาทั้งหมด (โทนมืด/สว่าง) |
| `config.js` | ตั้งค่าคีย์แผนที่และโมเดล |
| `src/data.js` | เนื้อหาภาษาไทย ดุอาอ์ พิกัดสถานที่ |
| `src/main.js` | ขั้นตอนและแผงควบคุม |
| `src/world.js` | ฉาก 3 มิติ แผนที่จริง การเดิน และการนับฏอวาฟ/สะแอ |
| `src/character.js` | ตัวละคร (โมเดลจากไฟล์ หรือหุ่นสำรอง) |
| `src/sites.js` | ประกอบแต่ละเมือง (อาคาร ถนน สถานที่ คน รถ) |
| `src/citymap.js` | สร้างอาคาร ถนน ภูมิประเทศ ต้นไม้ แผนที่ย่อ จากข้อมูลแผนที่ |
| `src/landmarks.js` | มัสยิดนะบะวีย์ โดมแห่งศิลา มัสยิดอัลกิบลีย์ และสถานที่สำคัญอื่น |
| `src/life.js` | รถยนต์และผู้คนในเมือง |
| `assets/maps/*.json` | ผังเมืองจริงที่ย่อขนาดแล้ว (อาคาร ถนน พื้นที่ ต้นไม้ ความสูงภูมิประเทศ) |
| `serve.ps1`, `เปิดเว็บ.bat` | เซิร์ฟเวอร์ในเครื่อง |

ลิงก์ทางลัดไปแต่ละขั้น: `http://localhost:8080/#tawaf` (ใช้ได้กับ create, prep, depart, miqat, tawaf, salah, sai, tahallul, return)

## ขึ้นเว็บจริง

อัปโหลดทั้งโฟลเดอร์ขึ้นโฮสต์แบบ static ใดก็ได้ เช่น Netlify (ลากโฟลเดอร์ไปวางที่ app.netlify.com/drop), Cloudflare Pages หรือ GitHub Pages แล้วอย่าลืมเพิ่มโดเมนนั้นในข้อจำกัดของ API key

> คีย์ใน `config.js` จะมองเห็นได้จากเบราว์เซอร์ทุกคน การจำกัดโดเมนในขั้นตอนที่ 4 คือสิ่งที่ป้องกันคนอื่นนำคีย์ไปใช้

## แหล่งข้อมูลแผนที่

- ผังอาคาร ถนน และสถานที่: © ผู้ร่วมพัฒนา OpenStreetMap (ใช้ภายใต้สัญญาอนุญาต ODbL) เว็บแสดงเครดิตไว้ที่ด้านล่างจอแล้ว ห้ามลบ
- ความสูงภูมิประเทศเยรูซาเล็ม: SRTM 30 ม. (ผ่าน OpenTopoData)
- อาคารที่ไม่มีข้อมูลความสูงในแผนที่ ใช้ความสูงประมาณตามย่าน และชานเมืองมะดีนะฮ์เติมบ้านเรือนตามแนวถนนจริง
