# โมเดลตัวละคร

วางไฟล์โมเดล (`.glb`, `.gltf` หรือ `.fbx`) ไว้ในโฟลเดอร์นี้ แล้วใส่ชื่อไฟล์ใน `manifest.json`
ช่องไหนเว้นเป็น `null` ระบบจะใช้หุ่นที่สร้างจากโค้ดแทน

| ช่องใน manifest | ใช้ตอนไหน |
|---|---|
| `male_travel` | ชายชุดเดินทาง (โต๊ปหรือเสื้อยาว) |
| `male_ihram` | ชายผ้าอิห์รอม 2 ผืน คลุมไหล่ทั้งสองข้าง |
| `male_ihram_idtiba` | ชายผ้าอิห์รอมเปิดไหล่ขวา ใช้ตอนฏอวาฟ (ถ้าไม่มีจะใช้ `male_ihram`) |
| `female_travel` | หญิงชุดคลุมและผ้าคลุมศีรษะ |
| `female_ihram` | หญิงในอิห์รอม (ชุดมิดชิด เปิดใบหน้าและฝ่ามือ) |

แอนิเมชัน: ถ้าในไฟล์โมเดลมีคลิปชื่อที่มีคำว่า `idle`, `walk`, `run` ระบบจะใช้เอง
ถ้าแอนิเมชันแยกไฟล์ (เช่น ดาวน์โหลดจาก Mixamo แบบ "Without Skin") ใส่ชื่อไฟล์ในช่อง `animations`
โมเดลกับแอนิเมชันต้องใช้โครงกระดูกชื่อเดียวกัน (เช่น rig ของ Mixamo ทั้งคู่)
ท่าละหมาด (`ruku`, `sujud`, `julus`) ใส่หรือไม่ใส่ก็ได้

ตัวเลือกอื่นใน manifest:
- `height` ความสูงที่ต้องการเป็นเมตร (ระบบย่อ/ขยายให้อัตโนมัติ)
- `rotateY` หมุนโมเดลถ้าหันผิดทาง (องศา)
- `tintMaterial` ชื่อวัสดุผ้าที่จะเปลี่ยนสีตามที่ผู้ใช้เลือก

## หาโมเดลได้จากไหน

ต้องเป็นโมเดลที่มีสิทธิ์ใช้งานถูกต้องเท่านั้น ห้ามนำโมเดลจากเว็บอื่น (รวมถึงเว็บต้นฉบับ) มาใช้โดยไม่ได้รับอนุญาต

1. **จ้างนักออกแบบ 3 มิติ** (Fastwork, Fiverr, ArtStation) ให้ปั้นตัวละครชุดอิห์รอม/โต๊ป/อาบายะฮ์ พร้อม rig ส่งเป็น GLB ได้ผลใกล้เว็บต้นฉบับที่สุด
2. **ทำเองฟรี**: สร้างร่างคนใน MakeHuman (ผลงานเป็น CC0) → แต่งชุดใน Blender → อัปโหลดไป Mixamo เพื่อใส่ rig และดาวน์โหลดแอนิเมชันเดิน/วิ่ง/ยืน → Export เป็น GLB จาก Blender
3. **ซื้อสำเร็จรูป**: ค้นใน Sketchfab, CGTrader, TurboSquid ด้วยคำว่า "ihram", "hajj pilgrim", "arab man thobe" เลือกที่มีป้าย Rigged และอ่านเงื่อนไขไลเซนส์ก่อนใช้

แนะนำให้แต่ละไฟล์ไม่เกิน 5–8 MB (ลดขนาดด้วย https://gltf.report หรือ gltf-transform) เพื่อให้โหลดเร็วบนมือถือ
